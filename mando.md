# Clase 1

## Comandos básicos de la terminal

- `ls`: lista los archivos de una carpeta.
- `ls -a`: lista todos los archivos, incluidos los ocultos.
- `clear`: limpia la terminal.
- `cd [carpeta]`: entra a una carpeta (`cd ..` vuelve a la anterior).
- `mkdir [carpeta]`: crea una carpeta.
- `rmdir [carpeta]`: elimina una carpeta vacía.
- `touch [archivo]`: crea un archivo.
- `rm [archivo]`: elimina un archivo.

## Atajos de VS Code

- `Ctrl + Ñ`: abre la terminal (en teclado en español).
- `Ctrl + S`: guarda el archivo.

## Comandos de Git

- `git init`: inicia un repositorio de git.
- `git status`: muestra qué archivos cambiaron.
- `git add .`: prepara todos los cambios para guardarlos.
- `git commit -m "mensaje"`: guarda una versión con un mensaje.
- `git push`: sube los cambios a GitHub.
- `git pull`: trae los cambios de GitHub.
